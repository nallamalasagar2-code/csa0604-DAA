Lossless Compression Enhancement

Our updated design utilizes a **Predictive Differential Layer**. Rather than encoding raw independent pixels, the pipeline encodes spatial error differences between adjacent neighbors. This concentrates counts near zero and drives up compression.

📊

Prefix Codeword Properties

Huffman produces prefix-free binary vectors. Because no code sequence serves as a valid prefix to another key, an encoded binary stream can be parsed sequentially without needing spacer symbols or delimiter blocks.

🛠️

The Greedy Min-Heap Paradigm

We utilize a bottom-up greedy framework. A priority queue constantly merges the two least frequent color differences. Highly active values finish closer to the root node, resulting in extremely compact bit representations.

⚡

Comparing JPEG Lossy Logic

JPEG processes image structures via frequency transformations (Discrete Cosine Transforms) and visual detail quantization, which permanently discards data. Huffman is entirely lossless, preserving raw physical arrays perfectly.

🏫

Critical Performance Math

The system dynamically computes Channel Entropy ($H$) and tracks code lengths ($L_{avg}$). The closer our average code length is to the Shannon entropy bound, the higher our algorithmic compression efficiency becomes.

Complexity Formulas

$$\text{Time Complexity: } O(N + n \log n)$$
$$\text{Space Complexity: } O(N + n)$$

Where $N$ is the overall pixel count ($W \times H$) and $n$ is the number of unique colors ($n \le 256$). Finding frequencies runs in $O(N)$ time. Min-Heap building takes $O(n \log n)$ time.

Selected Viva Q&As

Why is Huffman called a Greedy algorithm? ▼

It makes the locally optimal choice at each step (merging the two nodes with the absolute lowest frequencies) to construct an optimal global prefix code tree structure.

How does the predictive filter improve compression without losing quality? ▼

It utilizes reversible addition and subtraction equations modulo 256. Because neighboring pixels contain highly correlated values, their differences pack close to zero, which drops the Shannon entropy limit and creates shorter binary codes while remaining completely invertible.
